What is a supervisor agent?

A supervisor agent is a model whose job is to decide which of several specialised worker agents should act next, rather than performing the task itself. The pattern trades one large, general-purpose model doing everything for several smaller, focused models each doing one thing — plus a coordinator deciding the order.

Why this beats one model doing everything: a worker prompt written for exactly one job (research a company, retrieve from a knowledge base, draft a proposal) can be shorter, more testable, and easier to catch regressing than one enormous prompt trying to do all four at once — and a smaller, cheaper model can often do the routing decision itself, reserving the larger, more expensive model for the step that actually needs it.

In ACA, the supervisor runs on a small 8-billion-parameter model and picks the next worker — enrichment, knowledge retrieval, or drafting — from what has completed so far, appending its reasoning to a visible log a human can read before approving anything. The drafting step itself runs on a larger 70-billion-parameter model, reserved for the one task that genuinely needs it. Every worker returns control to the supervisor when done, except the drafting worker, which always goes to a self-critique step next — the one edge in the graph that is fixed rather than decided, because drafting is deliberately always the last worker to run.

The supervisor's model tier, its guardrails, and the fixed drafting-to-reflection edge are all directly readable in the compiled graph and covered by the project's graph-topology tests.
